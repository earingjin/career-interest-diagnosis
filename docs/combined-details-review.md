# 1·2순위 조합 상세 해석 검수표

- 원본: `src/content/combined-details.json` (version 0.1.0, reviewStatus `draft-needs-review`)
- 상태: **검수 전 초안**. 검수가 끝나면 JSON 의 `reviewStatus` 를 바꾸고 `version` 과 `src/content/version.ts` 의 `COMBINED_DETAILS_VERSION` 을 함께 올려 주세요.
- 화면 위치: 고객 모바일은 "나의 직업흥미 종합 해석" 바로 아래, 관리자 A4 는 2쪽 아래쪽 "나의 직업흥미 상세 해석(1순위 ○○형 + 2순위 ○○형)" 영역. 두 화면에 같은 문안이 나옵니다.
- 항목명: together = **두 흥미가 만나면**, connect = **경험에 연결해 보기**, balance = **균형 있게 살펴볼 점**

## 작성 기준 (자동 테스트로 확인하는 것은 ✔)

- ✔ 항목마다 70~100자, 한 조합 합계 200~300자 (A4 높이를 예측하기 위한 제한. 고칠 때도 이 범위를 지켜 주세요)
- ✔ 30개 조합끼리 같은 문장 없음, 기존 종합 해석과 같은 문장 없음, 1·2순위를 뒤집은 조합은 다른 문안
- ✔ 금지 표현 없음: 합격, 보장, 반드시, 적합합니다/적합한, ~해야 합니다, 틀림없, 확실히, 성격, 진단, RIASEC, 홀랜드, 연령대 표현
- ✔ 문장 끝은 "~니다." 또는 "~세요."
- 근거는 `interpretations.json` 의 두 유형 문안(핵심흥미, 업무방식, 선호활동, 업무환경, 부담활동, 경험활용, 탐색방향, 확인사항)입니다. 그 밖의 사실, 구체적 직업명, 자격·취업 가능성 단정은 넣지 않았습니다.
- 1순위를 중심("~이 중심이고/중심이며")으로, 2순위는 보완("~이 더해질 때")으로 썼습니다.

## 검수할 때 특히 봐 주세요

- 사실처럼 읽히는 표현이 없는지 (예: "보람이 더 커질 수 있습니다"처럼 가능성 어조를 유지했는지)
- 경험 예시(행사 소품, 민원 응대, 점검표 등)가 교육생에게 낯설지 않은지
- balance 항목의 "확인해 보세요" 대상(체력 부담, 감정 부담, 보수 구조 등)이 두 유형의 확인사항 범위 안에 있는지
